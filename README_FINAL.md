## 🎯 Цель проекта

Создать **ИИ-чат помощника для udmtpp.ru**, который:

- отвечает строго по фактам из базы, **без выдумывания**;
- использует **RAG + ChromaDB + Embeddings** для поиска информации;
- поддерживает **AI категоризацию** документов через DeepSeek;
- доступен через **веб-интерфейс** и **Telegram бот**.

## 🔍 RAG-процесс

1. **Запрос пользователя** → embedding через multilingual-e5-base
2. **ChromaDB** → поиск релевантного контента (top-5 из каждой коллекции)
3. **DeepSeek** получает только **контекст + запрос**
4. **Жёсткий system prompt** запрещает фантазии
5. **Confidence < 0.7** → система уточняет запрос
6. **Источники** + **оценка уверенности** в ответе

### System Prompt:

```
Ты — ассистент ТПП УР.
Отвечай только на основе предоставленного контекста. Не придумывай факты.
Если информации недостаточно — попроси уточнить вопрос.
Если найденные данные неуверенны (confidence < 0.7) — уточни вопрос.
Будь полезным и точным в ответах.
```

## 🚀 Быстрый старт

### 1) Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2) Настройка переменных окружения
```bash
cp .env.example .env
# Отредактируйте .env файл:
# - DEEPSEEK_API_KEY=ваш_ключ_от_deepseek
# - DEEPSEEK_BASE_URL=https://api.deepseek.com
# - TELEGRAM_BOT_TOKEN=ваш_токен_бота (опционально)
```

### 3) Загрузка данных из кеша
```bash
cd src
python -m uvicorn app:app --host 0.0.0.0 --port 8001 --reload
```

Затем откройте браузер и перейдите:
**http://localhost:8001/collections** → **"Rebuild from Cache"**

Или через API:
```bash
curl -X POST "http://localhost:8001/api/rebuild-from-cache"
```

### 4) Тестирование системы
```bash
# Запуск всех тестов
pytest -q --tb=no

# Проверка веб-интерфейса
# http://localhost:8001/ - Главная
# http://localhost:8001/chat - Чат с AI
# http://localhost:8001/collections - Управление данными
```

### 5) Запуск Telegram бота (опционально)
```bash
python src/bot.py
```
